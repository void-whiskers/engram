# Aesthetic Profile: Corporate Minimal

This profile defines a clean, professional, data-dense visual aesthetic suitable for enterprise tooling and B2B applications.

## Core Characteristics
- **Backgrounds**: Clean white or very light gray backgrounds to maximize readability. Subtle borders or drop shadows for depth.
- **Color Palette**: Muted, professional primary colors (e.g., navy blue, slate, subtle teal). Avoid overly saturated or neon colors.
- **Typography**: Highly legible sans-serif fonts (e.g., Helvetica, Inter). Emphasize hierarchy through font weight and size, not just color.
- **Data Density**: UI components should support high information density. Use compact padding and tight margins while maintaining readability (e.g., dense tables, compact forms).
- **Interactions**: Functional, snappy interactions. Avoid overly flashy animations. State changes (hover, focus) should be clear but understated.

## Application
When a project specifies this aesthetic, prioritize clarity, professionalism, and the ability to parse large amounts of data quickly. The UI should fade into the background, allowing the data and workflows to take precedence.

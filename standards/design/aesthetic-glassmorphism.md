# Aesthetic Profile: Neon Glassmorphism

This profile defines a futuristic, high-contrast, cyberpunk-inspired visual aesthetic.

## Core Characteristics
- **Backgrounds**: Dark, deep backgrounds (near black or very dark blues/purples).
- **Surfaces**: Frosted glass panels using CSS `backdrop-filter: blur()`, with semi-transparent rgba backgrounds.
- **Accents**: High-contrast, vibrant neon colors (cyan, magenta, electric blue, lime green) used for borders, active states, and glowing effects.
- **Typography**: Modern, sleek sans-serif fonts (e.g., Inter, Roboto Mono). High contrast for readability against dark backgrounds.
- **Micro-interactions**: Subtle glowing hover effects on buttons and interactive elements. Smooth transitions.

## Application
When a project specifies this aesthetic, all UI components must prioritize dark mode by default, utilize translucency for layered depth, and use neon accents sparingly but effectively to guide user attention.
